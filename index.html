Vista Sidebar

Оригінальні гаджети Windows Vista Sidebar — нативний C++, без HTML і браузера

⬇ Завантажити установник Скачати .msi
windowsSidebarSetup.exe · 4.1 МБ · Windows 7 / 10 / 11 (x64) · безкоштовно

🎞 SlideShow

Плавні переходи між фото, рамка, вибір своєї папки або вбудований Tulip.

🌦 Погода

Реальні дані: температура, стан неба, вітер та прогноз на 3 дні.

💰 Валюти

Курси CHF, USD, EUR та інших до гривні з живого курсу.

🧠 Picture Puzzle

Класичний пазл з картинкою — збирай по квадратиках.

📅 Календар

Місяць, дата й день тижня у справжньому вигляді Vista.

⚙️ Процесор

Навантаження CPU у реальному часі, оновлення щосекунди.

🕒 Годинник

Аналоговий циферблат з плавною стрілкою секунд.

🗂 Бічна панель

Панель зліва з усіма гаджетами — розташована за вікнами.

Що всередині

  • Нативний C++ + GDI+, жодного WebView2 та Chromium
  • Оригінальні PNG-зображення з пакетів .Gadget
  • Гаджети — окремі вікна: закриєш панель — вони залишаються
  • Перетягуй гаджети куди завгодно; панель закріплена
  • Правий клік по гаджету → Close gadget
  • Усі вікна «за» звичайними вікнами, без topmost
  • Конфіг і дані у %APPDATA%\VistaSidebar
  • Автозапуск разом з Windows (налаштовується в установці)
Встановлення: запусти windowsSidebarSetup.exe → Install. Після встановлення панель з'явиться ліворуч, гаджети — поруч.
Видалення: Панель керування → «Програми та компоненти» → Vista Sidebar.
